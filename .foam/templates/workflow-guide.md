# 🔄 Foam Workflow Guide

## 🚀 Getting Started

### 1. Install Foam Extension
- Open VS Code
- Go to Extensions (Ctrl+Shift+X)
- Search for "Foam"
- Install the Foam extension

### 2. Open Your Knowledge Base
- Open the `knowledge-base` folder in VS Code
- Foam will automatically detect and configure itself

### 3. Create Your First Note
- Use `Ctrl+Shift+P` → "Foam: Create New Note"
- Or use `Ctrl+Shift+P` → "Foam: Open Daily Note"

## 📝 Daily Workflow

### Morning Routine
1. **Open Daily Note**: `Ctrl+Shift+P` → "Foam: Open Daily Note"
2. **Review Yesterday**: Check previous day's notes and action items
3. **Set Today's Focus**: Use the daily note template
4. **Check Active Projects**: Review project status

### Throughout the Day
1. **Capture Ideas**: Use the inbox for quick thoughts
2. **Update Projects**: Add progress and notes
3. **Research Notes**: Document findings and insights
4. **Link Everything**: Connect related ideas

### Evening Routine
1. **Review Daily Notes**: Process the day's work
2. **Process Inbox**: Move items to appropriate locations
3. **Update Project Status**: Track progress
4. **Plan Tomorrow**: Set priorities for next day

## 🗺️ Navigation Tips

### Using the Graph View
- `Ctrl+Shift+P` → "Foam: Show Graph"
- Click and drag to navigate
- Use mouse wheel to zoom
- Click nodes to open notes

### Creating Links
- Type `[[` to start a link
- Use `[[note-name|display text]]` for custom display
- Links create backlinks automatically

### Using Tags
- Add `#tag` to categorize content
- Use consistent tagging system
- Combine tags for complex categorization

## 📚 Template Usage

### Available Templates
- **Daily Note**: `Ctrl+Shift+P` → "Foam: Open Daily Note"
- **Project Note**: Use project-note template
- **Meeting Note**: Use meeting-note template
- **Research Note**: Use research-note template
- **Artwork Note**: Use artwork-note template
- **Workshop Note**: Use workshop-note template

### Creating Custom Templates
1. Create template in `.foam/templates/`
2. Use `{{title}}`, `{{date:YYYY-MM-DD}}` for variables
3. Reference in VS Code settings

### External Links
