## Student screenshot storyboard
1. `01-reference-source.webp` — One centered reference, complete silhouette, neutral background. Show original + rights choice. Site stage: Reference.
2. `02-prompt-selected-image.webp` — Reference + prompt and selected concept. Capture own ChatGPT Images or Meshy Image Generation sample. Site stage: Generate.
3. `03-meshy-image-upload.webp` — Meshy 3D Model → Image to 3D, upload area with sanitized example; avoid personal/account metadata. Stage: Convert.
4. `04-meshy-generation-options.webp` — selected model type/quality and Generate action. Stage: Convert.
5. `05-meshy-orbit-front-back.webp` — two distinct angles of the same generated model (front and rear/underside) for structure inspection. Stage: Inspect.
6. `06-meshy-export.webp` — export/download format selection; prefer STL/GLB for source handoff. Stage: Convert.
7. `07-repair-before-after.webp` — Blender or slicer view of a bounded hole/loose component before/after, only if repair actually needed. Stage: Repair.
8. `08-bambu-scale-orient.webp` — dimension labels in mm, bed placement and support geometry. Stage: Scale/orient.
9. `09-bambu-slice-preview.webp` — Bambu Studio sliced layer preview and estimated time/grams, without printer/device identifiers. Stage: Slice.
10. `10-print-evidence.webp` — authorized machine printing a public-safe generic test piece, no bystander or private work visible. Stage: Print.

## Capture rules
- Use one consistent public-safe sample across the full pipeline, ideally designed for PLA MINI 35–70 mm.
- No third-party tutorial screenshots directly reused without permission; tutorials are learning references, not an implicit content license.
- Hide account details, generation IDs, billing, personal files and other customer models.
- Export 16:9 desktop capture for module hero; secondary 4:3 for tablet, and crop-safe 9:16 vertical for mobile. Source PNG at native resolution; web derivatives can be WEBP. Keep important UI in center safe area.
- Title/alt text and stage mapping accompany every asset. Attach consent/license provenance before publishing.
- If screenshots are from Meshy, capture using the version currently displayed; do not assume screenshots from older tutorials match Meshy 7.1.
- Do not stage imagery on the public website until rights and illustrative scope are validated.
