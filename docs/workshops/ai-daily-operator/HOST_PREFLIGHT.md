# Host preflight — Level I

Confirm these before the room opens. Core is 90 minutes. Studio is 2.5–3 hours. Same competency.

- Format: Core or Studio
- Cohort size
- Room or Zoom, screen, and a way to show one laptop
- Wi-Fi that can reach ChatGPT or Claude
- Each participant has a laptop or phone
- ChatGPT or Claude access. No calendar, email, finance, or CRM integration
- Accessibility needs asked in advance
- Privacy note ready to read aloud
- Synthetic fallback open for anyone who should not use real information
- Completion, assessment, and feedback expected before people leave
- After-action report assigned
