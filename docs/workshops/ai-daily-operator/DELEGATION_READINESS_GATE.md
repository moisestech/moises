# Delegation Readiness Gate — Founder Attention OS

A facilitator moves one rung at a time. This is not a license, and it is not an offer to any named teacher.

## Ladder

0. **Observe.** Watch a session and fill the scorecard. Do not teach.
1. **Co-facilitate.** Run a bounded segment while Moises holds the room.
2. **Lead with oversight.** Lead Core with Moises present.
3. **Approved independent facilitator.** Lead Core without Moises in the room. Still file an after-action report.

## Cannot advance unless all of these held in the observed session

- The four lenses: Commitments, Revenue or Mission, Risk, Capacity.
- Fact, interpretation, and recommendation stayed separate.
- Unknown stayed unknown.
- The sequence was recommend, explain, ask, then act.
- Friction was named before any automation.
- Privacy language and the synthetic fallback were ready.
- Completion, assessment, and feedback followed the Level I protocol.
- Core pacing held at 90 minutes.
