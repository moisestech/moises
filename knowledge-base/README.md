# 🧠 Moises Sanabria - Second Brain

Welcome to my digital second brain! This is a comprehensive knowledge management system built with [Foam](https://foambubble.github.io/foam/) for organizing thoughts, projects, research, and creative work.

## 🗂️ Directory Structure

### 📅 Daily Notes
- **Location**: `daily-notes/`
- **Purpose**: Daily journaling, task tracking, and quick thoughts
- **Template**: Uses daily-note template with focus areas

### 🎨 Projects
- **Location**: `projects/`
- **Purpose**: Active and completed project documentation
- **Template**: Project-note template with status tracking

### 🔬 Research
- **Location**: `research/`
- **Purpose**: Research notes, articles, and academic work
- **Categories**: Art theory, technology, AI, digital culture

### 🎭 Art & Creative Work
- **Location**: `art/`
- **Purpose**: Artwork documentation, concepts, and creative processes
- **Categories**: Installations, digital art, exhibitions

### 🎓 Workshops & Teaching
- **Location**: `workshops/`
- **Purpose**: Workshop content, teaching materials, and educational resources
- **Categories**: Digital presence, 3D lab, creative technology

### 🤝 Meetings & Collaboration
- **Location**: `meetings/`
- **Purpose**: Meeting notes, collaboration records, and communication
- **Template**: Meeting-note template with action items

### 📚 Resources
- **Location**: `resources/`
- **Purpose**: Reference materials, links, and external resources
- **Categories**: Tools, inspiration, documentation

### 📥 Inbox
- **Location**: `inbox/`
- **Purpose**: Quick capture of ideas, links, and temporary notes
- **Processing**: Regular review and organization into proper categories

## 🏷️ Tagging System

### Primary Tags
- `#project` - Project-related content
- `#research` - Research and academic work
- `#art` - Art and creative work
- `#workshop` - Workshop and teaching content
- `#meeting` - Meeting notes and collaboration
- `#idea` - Ideas and concepts
- `#resource` - Reference materials

### Status Tags
- `#active` - Currently active
- `#completed` - Finished work
- `#on-hold` - Paused or waiting
- `#archive` - Archived content

### Priority Tags
- `#high-priority` - Urgent and important
- `#medium-priority` - Important but not urgent
- `#low-priority` - Nice to have

## 🔗 Linking Strategy

### Internal Links
- Use `[[note-name]]` for linking to other notes
- Use `[[note-name|display text]]` for custom display text
- Create backlinks by referencing notes in multiple places

### External Links
- Use `[text](url)` for external resources
- Keep important links in the Resources section
- Use link references for frequently accessed URLs

## 📝 Note-Taking Guidelines

### Daily Notes
- Start each day with focus areas
- Capture quick thoughts and ideas
- End with tomorrow's priorities
- Review and process weekly

### Project Notes
- Use consistent project template
- Track progress and milestones
- Link to related research and resources
- Archive when completed

### Research Notes
- Include source citations
- Link to related concepts
- Use tags for easy discovery
- Regular review and synthesis

## 🚀 Getting Started

1. **Install Foam Extension** in VS Code
2. **Open Daily Note** using `Ctrl+Shift+P` → "Foam: Open Daily Note"
3. **Create New Notes** using `Ctrl+Shift+P` → "Foam: Create New Note"
4. **Explore Graph View** using `Ctrl+Shift+P` → "Foam: Show Graph"
