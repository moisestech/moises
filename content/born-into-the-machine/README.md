# Born into the Machine - Content Directory

This directory contains all the content for the "Born into the Machine" living book.

## Structure

- `chapters/` - Individual chapter markdown files
- `notes/` - Personal notes and reflections
- `conversations/` - Recorded AI conversations
- `metadata.json` - Book metadata and chapter ordering

## Chapter Format

Each chapter is a markdown file with frontmatter and content blocks marked with authorship indicators:

```markdown
---
title: "Chapter Title"
slug: "chapter-slug"
status: "draft" | "published"
created: "2025-01-15"
lastModified: "2025-01-15"
---

● This is human-written text, untouched by AI.

◐ This is hybrid text - I wrote it, but AI helped refine it.

○ This is AI-generated draft text, marked for critique and editing.
```

## Authorship Markers

- **●** (Human) - Written fully by the author, untouched by AI
- **◐** (Hybrid) - Co-written, where AI suggested or reshaped text
- **○** (AI Draft) - Text primarily generated by AI, marked for critique

## Editing

Chapters can be edited via the web interface at `/research/born-into-the-machine/[slug]/edit` or directly in these markdown files.

## Importing ChatGPT Conversations

To import ChatGPT conversations into your book:

1. **Export from ChatGPT** using the prompt in [`CHATGPT_EXPORT_PROMPT.md`](./CHATGPT_EXPORT_PROMPT.md)
2. **Save the formatted export** to `drafts/` folder
3. **Process the export:**
   ```bash
   node scripts/process-chatgpt-export.mjs your-file.md
   ```
4. **Map to chapters:**
   ```bash
   node scripts/map-to-chapters.mjs your-file.md
   ```
5. **Review and edit** in the web UI

See [`CHATGPT_EXPORT_PROMPT.md`](./CHATGPT_EXPORT_PROMPT.md) for detailed instructions.
