## Processing Workflow

### Step 1: Analyze Each File

For each file, go to:
`/research/born-into-the-machine/drafts/[filename]/read`

The system will:
1. Parse the file
2. Identify content blocks
3. Extract vocabulary, writers, books, artworks
4. Detect themes automatically

### Step 2: Review in Read View

1. **Scroll through** all content blocks
2. **Tag speakers** manually if needed (many will be "unknown")
3. **Tag themes** as you identify them
4. **Mark as processed** as you review each block
5. **Track progress** - see percentage complete

### Step 3: Use Categorization Dashboard

1. **Filter by speaker** - see all human vs AI content
2. **Filter by theme** - group related content
3. **Bulk tag** - select multiple blocks and tag themes
4. **Review statistics** - see what's been processed

### Step 4: Organize into Chapters

1. **Use Chapter Builder** - drag blocks into thematic chapters
2. **Preview chapters** - see how content flows
3. **Export chapters** - copy markdown ready for chapter files
4. **Refine organization** - reorder and adjust

### Step 5: Extract Entities

1. **Review vocabulary** - check extracted terms
2. **Review writers** - see all mentioned authors
3. **Review books** - check book references
4. **Review artworks** - see installation concepts
5. **Export all** - generate markdown files
