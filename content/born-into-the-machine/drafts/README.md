# Drafts Folder

This folder is for your raw ChatGPT conversations and draft content.

## How to Use

1. **Create a new file** for each ChatGPT conversation or topic
2. **Paste the raw conversation** directly into the file
3. **Name files descriptively**: `2025-01-15-slop-discussion.md` or `vocabulary-terms.md`
4. **The system will automatically detect and parse** these files

## File Naming Convention

- Use dates: `YYYY-MM-DD-topic.md`
- Use topics: `topic-name.md`
- Use categories: `vocabulary-*.md`, `questions-*.md`, `reflections-*.md`

## Supported Formats

Just paste your ChatGPT conversation as-is. The parser handles:
- `You: ...` / `ChatGPT: ...`
- `User: ...` / `Assistant: ...`
- JSON exports
- Plain text conversations

## Example Files

- `2025-01-15-introduction-discussion.md` - Conversation about book intro
- `vocabulary-definitions.md` - Key terms and definitions
- `questions-to-explore.md` - Questions from conversations
- `personal-reflections.md` - Your thoughts and notes
